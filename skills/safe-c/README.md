# safe-c

This skill instructs the agent to enforce rigorous safety, performance, and developer experience standards for C programming, heavily inspired by TigerBeetle's Tiger Style and "The Power of 10" rules.

## Use Cases & Triggers
- **Writing New Code:** "Write a new socket server in C using safe-c."
- **Refactoring:** "Refactor this C function to follow safe-c principles (remove dynamic allocations, bound loops, handle all errors)."
- **Reviewing:** "Review this PR for safe-c violations."
- **Memory Allocation:** "Optimize this buffer parsing to follow safe-c static allocation rules."

The specific guidelines, including instructions and reference links for detailed use-case examples, are defined in `SKILL.md`.
