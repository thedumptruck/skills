# safe-golang

This skill instructs the agent to enforce rigorous safety, performance, and developer experience standards for Go programming, inspired by "The Power of 10" and "TigerStyle".

## Use Cases & Triggers
- **Writing New Code:** "Write a new HTTP handler for user login using safe-golang."
- **Refactoring:** "Refactor this Go file to follow safe-golang principles (remove recursion, bound loops)."
- **Reviewing:** "Review this PR for safe-golang violations."
- **Memory Allocation:** "Optimize this buffer handling to follow safe-golang pre-allocation rules."

The specific guidelines, including instructions and reference links for detailed use-case examples, are defined in `SKILL.md`.
