# safe-ts

This skill instructs the agent to enforce rigorous safety, predictability, and zero technical debt standards for TypeScript programming, focusing on strict typing, immutability, and robust error handling.

## Use Cases & Triggers
- **Writing New Code:** "Write a new API endpoint in TypeScript using safe-ts."
- **Refactoring:** "Refactor this TypeScript function to follow safe-ts principles (use strict types, avoid any, pure functions)."
- **Reviewing:** "Review this PR for safe-ts violations."
- **State Management:** "Refactor this state logic to use immutable patterns according to safe-ts."

The specific guidelines, including instructions and reference links for detailed use-case examples, are defined in `SKILL.md`.
